# Portfolio Listing

**LabelForge AI — Independent Data Annotation & QA Benchmark**
Designed a synthetic customer-support annotation workflow covering intent, sentiment, urgency, and human-review routing. Authored annotation guidelines, created a labeled CSV dataset, and implemented Python checks for schema compliance, missing values, duplicate IDs, invalid labels, and label distributions. Included worked examples, an adjudication-log template, automated tests, and a transparent quality-report workflow.

**Tools:** Python, pandas, CSV, JSON, Git/GitHub
**Status:** Independent portfolio project; metrics should be populated after running validation and completing an independent review.
